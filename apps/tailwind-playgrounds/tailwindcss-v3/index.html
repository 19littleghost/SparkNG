SparkNG × Tailwind CSS v3

Live sandbox for the @bdspark/sparkng-tailwindcss plugin (loaded in tailwind.config.js). Every class below is generated by the plugin from the --p-* design tokens declared in tailwind.css.

Primary color

Semantic primary tokens: bg-primary, bg-primary-emphasis, bg-primary-emphasis-alt, text-primary-contrast.

bg-primary
bg-primary-emphasis
bg-primary-emphasis-alt
Aa
text-primary-contrast
text-primary border-primary bg-primary-50 / text-primary-700 ring-primary

Primary palette

The full primary-50 … primary-950 scale, each resolving to its --p-primary-* variable with alpha support.

50100200300400500600700800900950

Surfaces

Neutral surface-0 … surface-950 tokens used for backgrounds, borders and muted text.

Animations

Named keyframes (animate-fadein, animate-scalein, animate-zoomin, …) combined with the plugin's control utilities such as animate-duration-1000, animate-delay-500, animate-ease-out and animate-infinite.

animate-fadein animate-duration-1000
animate-scalein animate-duration-1000
animate-zoomin animate-duration-1000
animate-fadeinright animate-duration-1000
animate-fadein animate-delay-500 animate-ease-out
animate-fadein animate-duration-500 animate-infinite

Enter / leave transitions

The composable animate-enter keyframe driven by fade-in-*, zoom-in-* and slide-in-from-* modifiers — the primitives SparkNG components use for overlay transitions.

animate-enter fade-in-50
animate-enter zoom-in-95 slide-in-from-t-2
animate-enter fade-in-50 slide-in-from-b-4
